Split, combine and replace words in Time mode

Experimental, off by default: turn on **Word editing in Time mode** in Preferences. Right-click a word while syncing to split it (at the playhead when it is inside the word), combine it with the word before or after, or replace it. An extra option makes double-click edit the start time instead of the text.
