Edit mode tools: split typed lines, swap duet lines, reopen where you left off

Behind **Preferences › Editor & sync › Edit mode tools** (off by default): typing a whole line into **Insert word** gives separate words with your learned splits, and **Swap main and duet** flips every line (Tools menu) or the selection (line menu) in one undo step. Each project also reopens in Edit mode at the line you left it on, even after restarting the app.
